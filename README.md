# Telegram бот для сбора историй о наставниках

Простой бот для сбора ответов студентов о преподавателях-наставниках.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram

3. Создайте файл `.env` в корне проекта и добавьте:
```env
BOT_TOKEN=ваш_токен_бота_здесь
ADMIN_IDS=665509323,1478853053
CHAT_ID=ваш_chat_id_здесь
```

> 💡 Чтобы узнать свой Telegram ID, напишите боту [@userinfobot](https://t.me/userinfobot)  
> 💡 Если нужно несколько админов, укажите ID через запятую: `ADMIN_IDS=123456789,987654321`  
> 💡 **CHAT_ID** (опционально) — ID чата/канала, куда будут автоматически отправляться новые истории. Чтобы узнать ID:
>   - Для группы: добавьте бота [@userinfobot](https://t.me/userinfobot) в группу и напишите `/start`
>   - Для канала: перешлите любое сообщение из канала боту [@getidsbot](https://t.me/getidsbot)
>   - Для личного чата: просто ваш Telegram ID

4. Запустите бота:
```bash
python bot.py
```

> ⚠️ **Важно:** Файл `.env` не должен попадать в Git! Он уже добавлен в `.gitignore`

## Как работает

- При команде `/start` бот показывает приветственное сообщение
- Все текстовые сообщения сохраняются в два файла:
  - `stories.json` — JSON формат для программной обработки
  - `stories.txt` — читаемый текстовый файл для удобного просмотра
- Каждая история содержит: ID пользователя, имя, текст и время отправки
- **Если указан `CHAT_ID`**, все новые истории автоматически отправляются в указанный чат/канал

## Админ-команды

Если вы указали `ADMIN_IDS`, доступны команды:

- `/export` — получить все истории в удобном формате + JSON файл
- `/stats` — статистика по собранным историям

## Просмотр историй

### Вариант 1: HTML просмотр
Откройте файл `view.html` в браузере. Страница автоматически загружает данные из `stories.json` и обновляется каждые 30 секунд.

### Вариант 2: Через бота
Используйте команду `/export` в боте (требуются права админа).

### Вариант 3: Текстовый файл
Откройте файл `stories.txt` — все истории в удобном читаемом формате с нумерацией, датами и авторами.

### Вариант 4: Прямой доступ к JSON
Все истории сохраняются в файле `stories.json` в формате JSON для программной обработки.

## Тестирование

Проект включает набор тестов для проверки работоспособности всех компонентов бота.

### Запуск тестов

```bash
# Запустить все тесты
pytest

# Запустить с подробным выводом
pytest -v

# Запустить конкретный тест
pytest test_bot.py::TestFileOperations::test_save_story_new -v
```

### Что тестируется

- ✅ Работа с файлами (загрузка, сохранение историй)
- ✅ Обработчики команд (`/start`, `/export`, `/stats`, `/chatid`)
- ✅ Обработка сообщений от пользователей
- ✅ Проверка прав доступа для админ-команд
- ✅ Граничные случаи (пустой текст, специальные символы, юникод)
- ✅ Конфигурация и загрузка переменных окружения

Все тесты используют временные файлы и не влияют на реальные данные бота.
